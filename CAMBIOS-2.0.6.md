# Cambios 2.0.6

- Confirmaciones propias sin la casilla del navegador.
- Botón único **Agregar canción** con dos opciones: letra para clientes y letra para administradora.
- Selector de canciones ordenado alfabéticamente.
- Opción para crear una canción nueva desde el panel.
- Letras públicas y privadas guardadas por separado.
- Canciones nuevas ordenadas alfabéticamente.
- Avisos de guardado exitoso.

> En esta versión de prueba, las canciones y letras creadas desde el panel se guardan en el navegador del dispositivo. La sincronización multi-dispositivo con Firebase queda para el siguiente paso.
