# Entrega 6.36.42 · Imagen centrada al abrir

- El editor abre siempre con la imagen completa visible.
- La imagen se centra horizontal y verticalmente.
- El ajuste considera tanto el ancho como el alto de la pantalla.
- Si la imagen es pequeña, no se amplía innecesariamente.
- Después se mantiene disponible el zoom y desplazamiento normal.
