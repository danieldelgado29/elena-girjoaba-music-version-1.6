# Entrega 6.36.14 · Base estable del lápiz

Base: 6.36.8.

- Mantiene el menú estable anterior.
- Al cambiar color, grosor o tipo, el lápiz queda activo.
- El primer toque sobre la superficie cierra el menú y comienza el trazo inmediatamente.
- Muestras de color circulares; solo blanco con borde gris.
- No se modificaron borrador, texto ni carga de imágenes.
