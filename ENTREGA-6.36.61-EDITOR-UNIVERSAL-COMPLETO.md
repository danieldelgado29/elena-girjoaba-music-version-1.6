# Entrega 6.36.61 — Editor universal completo para Letra

- Editar letra abre el mismo editor completo usado por Editar imagen.
- El fondo del modo Letra es un lienzo blanco.
- La letra existente se carga como caja principal bloqueada.
- No se muestran las opciones de subir o eliminar fotografía.
- Se mantienen Texto, Negrita, Cursiva, Undo, Redo, Lápiz y Borrador.
- Cada caja incluye Eliminar, Alinear, Bloquear, Mover, Girar y Tamaño.
- Bloquear se activa o desactiva con doble clic o doble toque.
- Una caja bloqueada no permite escribir, mover, girar, redimensionar ni eliminar.
