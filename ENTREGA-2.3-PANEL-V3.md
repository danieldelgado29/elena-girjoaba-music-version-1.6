# Entrega 2.3 — Notas de Elena

- Nueva canción permite subir una imagen para las notas de Elena.
- Admite formatos de imagen comunes y `image/*`.
- Muestra nombre, vista previa y botón para quitar la foto.
- Convierte automáticamente las imágenes compatibles a JPEG optimizado para almacenamiento.
- La imagen queda asociada a la canción nueva en `notasElena`.
