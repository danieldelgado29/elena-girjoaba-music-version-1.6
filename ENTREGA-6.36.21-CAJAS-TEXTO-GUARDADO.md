# Entrega 6.36.21

- Texto mediante cajas independientes ancladas a la fotografía.
- Cada caja se puede mover, redimensionar, girar y eliminar.
- Las cajas se conservan como datos editables y se componen en la capa de anotaciones para el visor.
- El visor del panel se actualiza inmediatamente tras guardar.
- Fotografía, dibujo y texto permanecen en capas separadas.
