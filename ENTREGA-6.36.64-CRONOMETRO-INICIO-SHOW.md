# Entrega 6.36.64 – Cronómetro al iniciar show

- El cronómetro inicia automáticamente después de confirmar y guardar “Guardar configuración y comenzar show”.
- Cada nuevo show comienza desde 00:00:00.
- Doble clic o doble toque pausa/reanuda.
- “Finalizar show” detiene y reinicia el cronómetro.
- No se modificó el editor ni otras funciones del panel.
